# Livery Studio — страницы

Политика конфиденциальности и страница поддержки приложения Livery Studio,
редактора ливрей для Assetto Corsa Competizione (iOS и Android).

Отдельный репозиторий понадобился только затем, чтобы у этих страниц был
публичный адрес: App Store Connect и Google Play требуют ссылку на политику,
а App Store — ещё и на поддержку.

| Страница | Адрес |
|---|---|
| Поддержка, по-русски | https://islombeknasriddinov.github.io/livery-studio/ |
| Политика, по-русски | https://islombeknasriddinov.github.io/livery-studio/privacy.html |
| Support, in English | https://islombeknasriddinov.github.io/livery-studio/en/ |
| Privacy, in English | https://islombeknasriddinov.github.io/livery-studio/en/privacy.html |

Страницы не пишутся здесь руками: они собираются скриптом из разметки, которая
лежит вместе с исходниками приложения. Правки вносятся там и переносятся сюда
целиком.
